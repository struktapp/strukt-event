# 1.0.1 — Align base dependency on dev-main

## What changed

- `composer.json`: the `strukt/base` requirement moved from `dev-dev` to
  `dev-main`, and the `../../strukt4/base` path repository now pins the
  `strukt/base` version to `dev-main`.

## Why

- The rest of the strukt4 package set requires `strukt/base` as `dev-main` via
  pinned path repositories, while event alone required `dev-dev` (the inferred
  branch-`dev` version). This drift made it impossible to resolve a single
  `strukt/base` when installing packages such as `strukt/framework` together
  with event.

## Documentation

- None; packaging metadata only.

## Tests

- None; the change is validated by `composer install` in a consumer of both
  event and the broader strukt4 set.

## Public API impact

- None. Runtime behavior is unchanged; only the Composer resolution metadata
  was aligned.
