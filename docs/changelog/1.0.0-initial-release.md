# 1.0.0 — Initial strukt5 package with hardened Loop and Cmd

**Date:** 2026-10-11

**Changed**

- Established `strukt5/event` as the next-generation line of the package. It
  keeps the `strukt4/event` public API (so it is a drop-in replacement) and
  depends on `strukt/base` through the path repository `../../strukt4/base`.
- `Strukt\Loop::halt()` now replaces any previously registered terminal
  callback instead of queueing a second one. The old behaviour left stale
  `__halt_N` commands in the queue, where they executed once as ordinary
  commands before the real hook ran.
- `Strukt\Loop::run()` is now exception-safe. The terminal command and loop
  bookkeeping are cleaned up in a `finally` block, so a throwing command or
  hook no longer leaves a dangling halt command registered.
- `Strukt\Loop::run()` gained an optional `limit` option that caps the number
  of halt iterations (unbounded by default). Alias filtering now de-duplicates
  matched names.
- `Strukt\Cmd::add()` correctly distinguishes an argument array from an array
  callable such as `[$object, 'method']`. Previously such a callable was stored
  as both the callback and its own default arguments, so execution spread the
  object and method name as arguments. Both `(args, callback)` and
  `(callback, args)` orders are now supported.
- `Strukt\Cmd::doc()` caches descriptions until the command is replaced,
  removed, or reset.
- `Strukt\Event` gained `clear()` and `__invoke()`; `exec()` is unchanged.
- The package no longer sets `"symlink": false` on its path repository, so the
  base package's `vendor/` is not copied into this package's `vendor/`.

**Why**

- A review of `strukt4/event` found the halt-hook leak, non-exception-safe
  cleanup, the array-callable defect in `Cmd::add()`, repeated reflection in
  `doc()`, and a nested `vendor/strukt/base/vendor` footprint (~22 MB copied).
  This line fixes those while preserving the API so existing consumers keep
  working.

**Docs**

- `README.md`: documents `Event::clear()`/`__invoke()`, the relaxed `add()`
  forms, the `limit` and `alias` options, and the cleanup guarantee.

**Tests**

- `tests/Unit/EventTest.php`: expanded from 4 to 22 tests. New coverage for
  halt replacement, exception cleanup, the halt `limit`, the array-callable
  fix, callback-first defaults, explicit-argument override, filter errors,
  `doc()` caching, `clear()`, `__invoke()`, alias filtering, and the global
  helpers.

**API impact**

- Additive and compatibility-preserving. New: `Event::clear()`,
  `Event::__invoke()`, and the `limit` run option. Behavioural fixes: halt
  replacement and exception-safe cleanup in `Loop`; correct handling of array
  callables in `Cmd::add()`. No existing signature changed.
